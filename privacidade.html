Política de Privacidade

Adjetivos — Aplicativo para Discord


← Voltar para o início

1. Introdução

Esta Política de Privacidade explica como o aplicativo Adjetivos trata as informações utilizadas durante seu funcionamento dentro do Discord.

2. Informações que podem ser utilizadas

Para fornecer suas funcionalidades, o aplicativo pode utilizar informações necessárias para identificar usuários, servidores e interações realizadas com o aplicativo.

  • ID do usuário do Discord;
  • ID do servidor do Discord;
  • Respostas enviadas durante as dinâmicas;
  • Pontuações e resultados de quizzes;
  • Informações necessárias para funcionamento dos comandos.

3. Como as informações são utilizadas

As informações utilizadas pelo aplicativo têm como finalidade fornecer suas funcionalidades, registrar resultados das dinâmicas, calcular pontuações e disponibilizar rankings quando aplicável.

4. Compartilhamento de informações

O aplicativo não vende informações pessoais dos usuários. As informações utilizadas pelo aplicativo não são compartilhadas com terceiros para fins de publicidade.

5. Armazenamento e segurança

São adotadas medidas razoáveis para proteger as informações utilizadas pelo aplicativo contra acesso não autorizado, alteração ou divulgação indevida.

6. Exclusão de dados

Usuários ou administradores de servidores podem solicitar a exclusão de informações relacionadas ao funcionamento do aplicativo quando aplicável.

7. Alterações desta política

Esta Política de Privacidade pode ser atualizada quando necessário. A versão mais recente estará sempre disponível nesta página.

8. Contato

Para dúvidas, solicitações relacionadas aos dados ou outras questões sobre privacidade, entre em contato com o responsável pelo aplicativo Adjetivos.
